一、系统分层架构

从可视化编排、接口认证、双执行引擎、模型与工具运行时，到知识、记忆、媒体和持久化基础设施。

前端体验层

  • React 18、TypeScript、Vite、Ant Design、Tailwind CSS。
  • ReactFlow 画布、节点库、节点配置面板和工具栏。
  • 调试抽屉、流式事件时间线、Markdown/多媒体结果。
  • 知识库、MCP 工具与全局模型配置管理页面。

接口与安全层

  • 登录、登出、刷新令牌、当前用户接口。
  • JWT Access/Refresh Token 与认证拦截器。
  • 工作流、执行、知识库、MCP、模型、技能、媒体 API。
  • Swagger/OpenAPI 与统一 `Result` 响应结构。

工作流引擎层

  • EngineSelector 按 `engineType` 自动路由。
  • 自研 DAG：Kahn 拓扑排序、DFS 循环检测、顺序调度。
  • LangGraph4j：StateGraph、条件边、动态路由、状态管理。
  • NodeExecutorFactory 将节点类型映射到执行器。

AI 与工具层

  • OpenAI、DeepSeek、通义千问、阶跃、智谱、Agnes、Agent Plan 等。
  • ReAct Agent、内置工具、MCP、Web Search/Fetch。
  • TTS、图片生成、视频生成、视觉分析。
  • Skills、Agent 记忆、知识库检索与写入。

数据与运行层

  • MySQL：工作流、节点定义、执行记录、快照、变量、知识、配置。
  • MinIO：生成图片、视频、音频等媒体持久化。
  • SSE：节点启动、进度、成功、失败和流程完成事件。
  • 执行快照与变量支持断点续执行和故障恢复。

01

登录、认证与会话保障

为工作流、知识库和模型配置提供统一身份入口。

基础
  • 用户名密码登录，返回 Access Token 与 Refresh Token。
  • 刷新令牌、当前用户查询、登出和前端认证状态清理。
  • 后端拦截器校验 Bearer Token，公开登录接口除外。
  • 前端路由默认跳转编辑器，未登录请求统一处理。
  • JWT 密钥配置校验与默认用户初始化。

画布

04

DAG 与 LangGraph 双执行引擎

简单流程用 DAG，复杂条件与状态路由用 LangGraph。

引擎
  • EngineSelector 根据工作流 `engineType` 自动选择执行器。
  • DAG：解析节点/边、Kahn 拓扑排序、DFS 循环检测和节点数据流转。
  • LangGraph：构建 StateGraph，支持条件边、动态路由和异步节点动作。
  • NodeAdapter 复用现有 `NodeExecutor`，避免重复实现节点业务。
  • StateManager 统一管理输入、节点输出和全局上下文。
  • 执行器统一提供同步执行和带事件回调的流式执行。
代码入口
EngineSelectorWorkflowEngine DAGParserLangGraphWorkflowEngine GraphBuilderNodeAdapter StateManager
05

节点库与基础控制节点

当前编辑器可直接使用的核心节点组件。

节点
  • 输入节点：接收调试输入和工作流初始数据。
  • 输出节点：定义输出参数，展示文本、图片、音频和视频结果。
  • 通用大模型节点：承接多 Provider 模型调用与 Agent 策略。
  • TTS 节点：文本转语音并输出音频 URL、文件名与时长。
  • 条件分支节点：支持等值、大小、包含、前缀、后缀、空白等 12 类运算。
  • 图片生成与视频生成节点：调用具备图片/视频能力的全局模型配置。
  • 节点定义由后端 `/api/node-types` 动态加载，可按分类展示。
代码入口
NodeDefinitionServiceNodePanel InputNodeExecutorOutputNodeExecutor ConditionNodeExecutorTTSNodeExecutor
06

多模型 Provider 与通用 LLM 节点

统一接入多家 OpenAI 兼容或原生模型服务。

模型
  • Provider 覆盖 OpenAI、DeepSeek、通义千问、阶跃星辰、智谱、AIPing、Agnes、APIFree/SkyClaw 和火山方舟 Agent Plan。
  • 通用 LLM 节点可选择全局配置，也可在节点内手工填写 API 地址、Key 和模型。
  • 支持模型名称、温度、提示词、最大推理步数、输入参数和输出参数。
  • ChatClientFactory 按 Provider 动态创建 Spring AI ChatClient。
  • 保留 OpenAI、DeepSeek、Qwen、Step、ZhiPu、AIPing 等历史专用执行器以兼容旧流程。
  • 提示词模板可从输入与上游节点输出中引用数据。

07

ReAct Agent 与多步骤工具调用

让大模型自主决定调用哪些工具、何时给出最终答案。

Agent
  • 通用 LLM 节点可切换 `agentStrategy=react`，或兼容旧的 `react_agent` 节点。
  • 配置最大步骤数，循环执行“思考 → 调用工具 → 观察 → 继续决策”。
  • 支持内置工具、联网工具、知识检索、记忆读写和 MCP 工具共同参与。
  • 输出 `finalAnswer`、`toolTrace`、步骤数和 Token 信息。
  • 调试面板显示每次工具调用、输入摘要、观察结果与失败原因。
  • 达到最大步数后可强制生成最终答案或返回已收集信息。
代码入口
ReActAgentNodeExecutorAgentToolRegistry AgentToolContexttoolTrace agentStrategymaxSteps

TTS 文本转语音

把大模型生成内容转换为可播放、可下载的音频结果。

音频

  • 可引用全局配置，也可在节点内填写 API 地址、Key 和模型。

  • 长文本自动分片合成，并将多段音频拼接为一个结果。
  • 通过 SSE 返回分片合成进度，便于调试长任务。
  • 最终输出音频 URL、文件名、时长和文件大小；前端提供播放与下载。

五、关键流程拆解

五个典型流程覆盖平台最主要的用户价值。

零代码构建文本工作流

  1. 登录并配置 Provider、API 地址、Key 和默认模型。
  2. 新建工作流，拖入输入、LLM、输出节点。
  3. 连接节点并配置提示词、温度、输入参数和输出参数。
  4. 保存后打开调试抽屉，输入文本执行。
  5. 查看流式日志和最终 Markdown 输出。

ReAct 工具型 Agent

  1. 在通用 LLM 节点选择 Provider 和模型。
  2. 将 Agent 策略切换为 ReAct，设置最大步骤数。
  3. 勾选知识检索、记忆、联网或 MCP 工具。
  4. 后端循环执行思考与工具调用，并记录工具轨迹。
  5. 输出最终答案，调试面板展示每一步观察结果。

企业知识问答

  1. 创建知识库，选择 Agent Plan 和 Embedding 模型。
  2. 导入文本或上传 Markdown/TXT 文档。
  3. 预览分片并建立索引，观察索引任务进度。
  4. 在 LLM 节点或 Agent 中选择知识库并设置 Top K。
  5. 执行检索，返回相关片段、引用与拼装上下文。

AI 播客与多模态生成

  1. 输入主题，由 LLM 结合 `ai-podcast` Skill 生成脚本。
  2. 脚本传入 TTS 节点，配置音色、语速和采样率。
  3. 长文本自动分片合成，SSE 展示实时进度。
  4. 输出音频并在调试面板播放或下载。
  5. 可继续串联图片或视频节点，形成完整内容包。

复杂条件与断点恢复

  1. 选择 LangGraph 引擎，以状态图表达条件分支与动态路由。
  2. 执行过程中通过 SSE 观察节点状态和进度。
  3. 失败后查询执行快照、节点结果和上下文变量。
  4. DAG 工作流可修改变量、跳过成功节点并从指定节点恢复。
  5. 成功后保留完整执行记录，便于审计和回看。

七、适用场景与实现边界

适用场景

  • 内容生成：批量文章、改写润色、多语言内容。
  • 智能客服：意图识别、知识问答、多轮工具调用。
  • 数据处理：文本分析、信息抽取、清洗和转换。
  • 音视频生产：脚本、TTS、图片和视频组合生成。
  • 流程自动化：报告生成、定时任务、外部系统调用。

当前实现边界

  • 前端节点库不直接展示所有内部节点，部分 Agent 能力通过通用 LLM 节点启用。
  • MCP 页面当前主要提供 Agent Plan 联网搜索预设，不包含完整自定义工具编辑器。
  • 视频生成属于长任务，受 Provider 配额、轮询时长和网络稳定性影响。
  • 知识库、记忆、图片/视频生成需要正确的 Provider 密钥与模型名。
  • MinIO、MySQL 和外部模型服务是运行依赖；未配置时相关能力不可用。
  • 当前代码未体现完整多租户、组织级 RBAC 和工作流市场。
